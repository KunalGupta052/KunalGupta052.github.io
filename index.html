About & Philosophy

I entered software engineering through the operating system. Before writing API handlers or designing database tables, I was configuring RHEL environments, managing storage with LVM, and writing Bash scripts to streamline system tasks. That foundation gives me a unique perspective on backend engineering.

Today, I build Python and Flask microservices that bridge software logic with real infrastructure — triggering Ansible playbooks over SSH, interacting with containerized workloads on Podman, and enforcing structured data validation. I don't stop at "it runs on my local machine" — I care about how software is packaged, tested, logged, and executed in production Linux environments.

PROJECT 01 INFRASTRUCTURE AUTOMATION DASHBOARD

RHEL Fleet Manager

Flask control plane for executing Ansible playbooks and tracking live status across multi-node Linux fleets.

PROBLEM

Executing repetitive administration operations—user lifecycle, package installation, service monitoring, log rotation—manually across multiple Linux nodes is error-prone and lacks observable execution state.

WHAT I BUILT

Engineered a Flask web interface that triggers Ansible playbooks over SSH against target inventory groups, recording execution state and output logs into a database for historical auditing and live web visualization.

ENGINEERING HIGHLIGHTS

  • Simulated multi-node Linux fleet using Podman containers on a RHEL 9 VM for safe execution testing.
  • Programmatic Ansible playbook invocation via Python background execution handlers.
  • SQL logging of playbook execution runs, host responses, and task exit codes.
  • Centralized user management, package provisioning, and systemd monitoring commands.
